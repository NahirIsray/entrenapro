# 🏋️‍♂️ FLG PERSONAL TRAINER - Plataforma de Rutinas y Rendimiento Deportivo

Plataforma web moderna y PWA pensada para **Facu LG (Entrenador Personal)** y sus **Atletas y Alumnos**. Permite sincronizar rutinas directamente desde Google Drive (Google Sheets), llevar registro de cargas, RPE y ver videos demostrativos de cada ejercicio sin salir de la app.

---

## ⚡ Tecnologías

- **Frontend:** React 19 + TypeScript + Vite
- **Estilos & Iconos:** Tailwind CSS + Lucide React
- **Celebraciones & Animaciones:** Canvas Confetti + Web Audio API
- **Base de Datos & Tiempo Real:** [Supabase](https://supabase.com) (PostgreSQL + Realtime)
- **Despliegue:** [Vercel](https://vercel.com)
